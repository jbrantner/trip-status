Trip Status

Editing mode

Connect this device once. The key is saved on this device only.

  1. Open GitHub's new token page.
  2. Name it "Trip Status" and pick an expiration (up to a year).
  3. Repository access: "Only select repositories", pick trip-status.
  4. Permissions: set Contents to "Read and write". Tap Generate and paste the key here.

Tap Edit on a trip to change it. Nobody else sees changes until you tap Save.
